# Components

The initial SDK release targets the components below.

## RHAPSODY

Unified AI+HPC runtime supporting services alongside tasks (extends
RADICAL-Pilot). RHAPSODY orchestrates coupled AI-and-simulation
ensembles across heterogeneous resources.

- Repository: <https://github.com/radical-cybertools/rhapsody>
- Documentation: <https://rhapsody-py.readthedocs.io/>
- PyPI: <https://pypi.org/project/rhapsody-py/>
- Remote access (RHAPSODY-as-a-Service) via ORBIT:
  <https://github.com/radical-cybertools/radical.orbit>, documented at
  <https://radicalorbit.readthedocs.io/>

## AsyncFlow

Asynchronous workflow layer for scalable HPC pipelines.

- Repository: <https://github.com/radical-cybertools/radical.asyncflow>
- Documentation: <https://radicalasyncflow.readthedocs.io/>
- PyPI: <https://pypi.org/project/radical-asyncflow/>

## SEEKRFLOW

Biomolecular rate-constant estimation workflows built on SEEKR2.

- Repository: <https://github.com/seekrcentral/seekrflow>
- Documentation: <https://github.com/seekrcentral/seekrflow/tree/main/docs>
- SEEKR2 documentation: <https://seekr2.readthedocs.io/en/latest/>

## QuAcc

Quantum chemistry workflow recipes for high-throughput materials
science.

- Repository: <https://github.com/Quantum-Accelerators/quacc>
- Documentation: <https://quantum-accelerators.github.io/quacc/>

## Rootstock

Run pre-deployed machine learned interatomic potentials on HPC clusters without managing conflicting dependencies.

- Repository: <https://github.com/Garden-AI/rootstock>
- Model catalog: <https://garden-ai.github.io/almanac/>

## DeepDriveSim

Deep learning-driven Adaptive Simulations.

- Repository: <https://github.com/radical-collaboration/DeepDriveSim>
- Documentation: <https://radical-collaboration.github.io/DeepDriveSim/>
