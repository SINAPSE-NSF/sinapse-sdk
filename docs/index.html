About SINAPSE

SINAPSE — Scalable Infrastructure for AI-coupled Predictive Simulation Enhancement — is a research effort to make AI models and physical simulations work together fluidly on high-performance computing systems. This SDK gathers its interoperable components in one place. It's early: expect it to grow as more tools join the network.

Supported by NSF Award #2514142: “Collaborative Research: Frameworks: SINAPSE: Scalable Infrastructure for AI-coupled Predictive Simulation Enhancement.”
